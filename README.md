# 웨이퍼 맵 시뮬레이터

웨이퍼 테스트 데이터(W07, W21)로 웨이퍼 맵, 불량률, 합격 수치를 보고 불량 패턴을 익히는 학습용 대시보드입니다.

- `index.html`: 대시보드 (정적 페이지, 외부 라이브러리 없음. 글꼴만 Google Fonts에서 불러옵니다)
- `wafer-data.json`: die별 측정값과 판정 (W07·W21 각 616칸)
- `rules.json`: 합격 기준표의 판정 규칙과 화면 이름

`index.html`은 같은 폴더의 두 JSON 파일을 `fetch`로 읽으므로, 파일을 직접 여는 대신 웹 서버(예: GitHub Pages)로 열어야 합니다.

데이터에는 불량 원인이 없어서, 원인 설명은 포함하지 않습니다. 가상 웨이퍼는 학습용 합성 데이터입니다.
